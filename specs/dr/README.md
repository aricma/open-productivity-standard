# Decision Records (DR)

The decisions we have locked, one file per decision: `DR-NNN-short-title.md`.
Each DR records what was chosen, why, and the context it leaves behind, and
is immutable — changing one means a follow-up RFC that lands as a new DR.

A decision that is still open lives in [`../rfc/`](../rfc/README.md). The
[decision process](../README.md) defines what an RFC and a DR are, and the
lifecycle between them.
