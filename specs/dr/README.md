# Decision Records (DR)

A **decision record** is an immutable record of a decision we have locked:
what was chosen, why, and the context it leaves behind. Once locked, a DR
is never edited — changing one means a follow-up RFC that lands as a new
DR that supersedes it.

Every DR is one file, `DR-NNN-short-title.md`.
