# Open Productivity Standard (OPS)

The specification for an open, tool-agnostic data model for exchanging
tasks between productivity tools. See the [repo root](../README.md) for
the pitch.

**Status:** version 0, draft — not released, may change.

## Read order

1. [`v0/`](v0/README.md) — version 0: the model and its formats. Each
   version of the standard lives in its own directory, with its own
   decision records and its own test corpus.
2. [`CHANGELOG.md`](CHANGELOG.md) — the specification history.
